- Refuse existing target file/directory and preserve sentinels. Final publication follows content/hash verification, then durable report/job persistence before public completed state. Reports preserve source list/count/fingerprint, input kind/dialect, mapping/filter snapshot, selected/excluded/written counts, MIME differences and final output verification.

### Proven raw-input path: backend implementation authorized

Root isolated the msg-11 loss to the experiment's unnecessary `MimeKit.WriteTo` reserialization. Reading the same original raw EML bytes directly with Aspose retains the original plain part plus the measured vendor prefix. Both parsers must consume the same immutable raw MIME bytes; do not pass a MimeKit-reserialized message to Aspose. For MBOX, supply the raw record after exactly one mboxrd unescape before MIME decoding.

Root tested 12 raw EML and 12 raw mboxrd records with direct `MapiMessage.SetProperty(KnownPropertyList.Body, expectedMarkedPlain)`, where expectedMarkedPlain is the exact original source plain plus the retained measured vendor prefix. Do not obtain it by re-reading a MailMessage.Body setter/getter pair. SDK load drops exactly one final LF in msg-09/10 on this raw path; this narrowly measured change is corrected from the original parser value and explicitly reported. No general whitespace trimming, arbitrary marker extraction or swallowing unknown differences. Keep original HTML and SDK HTML evaluation wrapper; report any generated representation separately.
